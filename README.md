# SendPulse.Net

A modern, lightweight .NET client for [SendPulse REST API](https://sendpulse.com/api), supporting OAuth2, mailing lists, templates, and campaigns.

## 🚀 Features
- OAuth 2.0 (client credentials) authentication
- Address books management (create, list, delete)
- Bulk email import (single / double opt-in)
- Template CRUD (create/update/delete)
- Extensible for campaigns and SMTP

## 🧩 Installation
```bash
dotnet add package SendPulse.Net
